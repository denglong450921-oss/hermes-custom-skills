## Query optimization tips

- Use 3-5 English keywords for best matching
- Include one "strong keyword" from the category
- Avoid very narrow terms like specific brand names
- If first query scores < 0.7, retry with broader terms
- Example: "quantum computing startup" → "tech startup business"
