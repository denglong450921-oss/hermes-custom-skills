> 真正的自动化不是省掉人工，而是让人工只处理机器无法可靠判断的部分。

## 问题：生成完成不等于可以发布

许多团队已经能快速生成文章，但无法回答证据是否完整、HTML 是否适配手机、
失败后应该重跑哪一个阶段。

## 结构：把流程拆成原子能力

| 阶段 | 输入 | 输出 |
|---|---|---|
| 证据核验 | 来源与主张 | 证据账本 |
| 内容深化 | 草稿与账本 | 可验证文章 |
| 排版适配 | Markdown | 微信 HTML |

```python
def gate(report):
    return all(score >= 90 for score in report.values())
```

## 行动：先建立最小闭环

1. 明确每一步的输入输出。
2. 为失败定义重启范围。
3. 发布前保留人工预览。
