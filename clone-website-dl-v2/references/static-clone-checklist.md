# Final Static Clone Checklist

Use this before delivery.

- [ ] `SOURCE_OF_TRUTH.md` exists for every cloned page.
- [ ] Header/navigation is an independent reusable component.
- [ ] Footer is an independent reusable component.
- [ ] Every visible section has a component spec.
- [ ] Sections are assembled in source order.
- [ ] Visible text is verbatim.
- [ ] Fonts, colors, spacing, and breakpoints are evidence-backed.
- [ ] Localized assets are under the budget.
- [ ] Over-budget or blocked media has documented placeholders.
- [ ] No blank media area exists without an explanation.
- [ ] No animation reconstruction code was added unless the user explicitly requested it.
- [ ] Build/type/test commands pass.
- [ ] Asset budget check passes.
- [ ] Component boundary check passes.
- [ ] Stage detector reports exist and pass.
- [ ] Final QA report exists and passes.
