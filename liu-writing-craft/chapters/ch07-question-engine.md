# Chapter 7: 初阶：问题是文章的引擎

## Core Idea
没有问题，写作就只剩材料堆砌；问题决定靶心、角度和回答方式。

## Frameworks Introduced
- **三步提问法**: 领域 -> 主题 -> 问题。
  - When to use: 从模糊兴趣发展出论文题目。
  - How: 先选领域，再缩小主题，最后形成可回答、可验证、可表达的问题。
- **沙漏写作法**: 从宽背景进入窄问题，再从具体发现回到较大意义。
  - When to use: 写引言和选题说明。
  - How: 背景宽开，问题收窄，结尾再说明意义。
- **聊天测试**: 用普通话向非专业朋友说清问题。
  - When to use: 检验题目是否可理解。

## Key Concepts
- **议题**: 大范围话题。
- **难题**: 实践中要解决的麻烦。
- **疑问**: 研究中可回答的具体问题。

## Mental Models
- Use **engine** when deciding whether a draft can move.
- Think of questions as steering, not decoration.

## Anti-patterns
- **中国留守儿童问题研究**式大题目。
- **无端生事/无米下锅/无人问津**等坏问题。

## Worked Example
“社交媒体与睡眠”太大。缩为：“社交媒体日均使用时长对18-25岁城市青年睡眠质量有何影响？”对象、变量、范围和可能证据都更清楚。

## Key Takeaways
1. 提问是写作最难也最关键的一步。
2. 好问题需要阅读、思考和反馈。
3. 问题越清晰，材料越会自动分工。
4. 题目必须缩到可做。
