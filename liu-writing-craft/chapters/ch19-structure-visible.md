# Chapter 19: 结构：化无形为有形

## Core Idea
结构把无形思想变成可见路径，为作者提供脚手架，也为读者提供导航。

## Frameworks Introduced
- **结构层级**: 微观词句、中观段节、宏观篇章。
  - When to use: 定位文章混乱的层级。
  - How: 先看宏观顺序，再看段落功能，最后修句子。
- **组织原则**: 范畴、评价、时间、比较、线性、因果。
  - When to use: 安排章节和段落。
  - How: 根据论证目的选择一种主导结构。
- **形式主义/浪漫主义张力**: 规则能降低难度，但不能压死思想。

## Key Concepts
- **有机论文**: 各部分互相支撑的整体。
- **脚手架**: 写作时临时支撑思想的结构。
- **宏观结构**: 文章整体组织。

## Mental Models
- Use **structure as mesh**: 软材料靠结构变坚固。
- Think of outline as a build plan, not a prison.

## Anti-patterns
- **随心所欲**: 没有读者路径。
- **机械套模板**: 结构存在但不服务问题。

## Worked Example
解释一个政策变化，可选时间结构；比较两个城市，可选比较结构；解释差异原因，可选因果结构。先确定目的，再选结构。

## Key Takeaways
1. 结构降低写作难度。
2. 不同问题需要不同组织原则。
3. 结构必须服务论证。
4. 先宏观后微观修改更有效。
