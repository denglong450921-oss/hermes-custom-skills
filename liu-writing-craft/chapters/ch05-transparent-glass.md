# Chapter 5: 好的文字如同透明玻璃

## Core Idea
说理写作的上乘风格是清楚：读者透过文字看见对象，而不是被文字本身绊住。

## Frameworks Introduced
- **透明玻璃文风**: 文字像窗玻璃，本身不抢戏，让思想和事实顺畅抵达读者。
  - When to use: 写论文、报告、解释型文章。
  - How: 短段落、可跟踪主语、具体词、必要术语、清楚衔接。
- **易读难写定律**: 看似简单顺畅的文字最难写，因为作者要替读者承担组织成本。
  - When to use: 修订自以为“太朴素”的文字。
  - How: 把复杂性留在思考中，把清楚留给读者。

## Key Concepts
- **阅读体验**: 文字风格给读者造成的实际负担。
- **彩色玻璃**: 华丽但遮挡对象的文字。
- **朴素力量**: 克制、准确、节制形成的表达强度。

## Mental Models
- Use **window glass** when choosing between ornament and clarity.
- Think of style as reader ergonomics.

## Anti-patterns
- **以难懂冒充深刻**。
- **把风格当装饰**，而不是信息传递方式。

## Worked Example
比较两种写法：A“本文拟从多维度视角展开综合性探讨”；B“本文解释为什么有些课程逃课多，有些课程逃课少”。B更透明，因为读者立刻知道对象、差异和问题。

## Key Takeaways
1. 清楚是说理写作的美德。
2. 好文字降低读者成本。
3. 简单不是浅薄，可能是高水平加工。
4. 风格首先服务理解。
