# Chapter 16: 文雅地抬杠：如何与文献对话？

## Core Idea
学术写作是一场有礼貌的抬杠：先听懂别人，再说出自己能推进什么。

## Frameworks Introduced
- **They say/I say**: “他们说了什么/我要说什么”的攻辩结构。
  - When to use: 写文献综述、引言、研究定位。
  - How: 概括现有观点，指出不足、空白或争议，再提出自己的介入。
- **文献五问**: 动机、问题、观点、方法/证据、与我关系。
  - When to use: 阅读和整理每篇文献。
  - How: 每篇文献只保留能服务对话的结构化信息。
- **凝结核**: 在大量文献中找到能凝聚讨论的核心关系或争点。

## Key Concepts
- **对话**: 接话、转话、反驳、补充。
- **攻辩结构**: 观点之间的张力。
- **文献关联度**: 文献与自己问题的距离。

## Mental Models
- Use **entering a room**: 先听大家聊什么，再开口。
- Think of literature notes as ammunition for precise disagreement.

## Anti-patterns
- **礼貌性罗列**: 每人一句，互不相干。
- **没听懂就反驳**。

## Worked Example
读三篇关于算法管理的论文后，不按作者顺序写，而写：“已有研究强调控制，但较少解释劳动者如何利用平台规则反向调节工作节奏。本文从这一空白进入。”

## Key Takeaways
1. 文献综述的核心是对话。
2. 反驳要先准确概括。
3. 文献五问能把阅读转成写作。
4. 好综述能自然推出自己的问题。
