# Chapter 18: 论证的树形结构

## Core Idea
好论证像树：问题是根，观点是树干，理由是树枝，证据是树叶。

## Frameworks Introduced
- **树形论证**: 问题-观点-理由-证据层层支撑。
  - When to use: 草稿散乱或证据堆砌。
  - How: 先写问题，再写一句主张，然后列理由和对应证据。
- **观点类型**: 事实、价值、政策、概念、解释。
  - When to use: 判断需要什么证据。
  - How: 不同观点匹配不同证明方式。
- **证据评估**: 准确性、精确性、代表性、可靠性、主观性。

## Key Concepts
- **假说**: 对问题的猜测性回答。
- **理由**: 支撑观点的中间命题。
- **证据**: 支撑理由的材料。

## Mental Models
- Use **argument tree** before drafting sections.
- Think of evidence as leaves: many leaves cannot save a broken trunk.

## Anti-patterns
- **断头文章**: 只有问题没有回答。
- **证据倾倒**: 材料很多但不知道证明什么。
- **废话理由**: 理由只是重复观点。

## Worked Example
问题：中国某时期医生为何多于护士？观点：制度和职业结构造成护理职业发展受限。理由可分为教育供给、医院岗位、性别分工、政策激励；每条理由配数据或文献。

## Key Takeaways
1. 问题必须导向观点。
2. 理由连接观点和证据。
3. 证据质量比数量重要。
4. 树形图能暴露论证缺口。
