# Chapter 29: 如何克服写作障碍？

## Core Idea
写作障碍通常来自没的写、不会写、不想写；破局要先让文字流动，再谈质量。

## Frameworks Introduced
- **先有后好**: 先生产粗稿，再修订。
  - When to use: 卡在空白页。
  - How: 限时自由写、口述转文字、先列材料，不许边写边审判。
- **以说带写**: 用说话降低启动难度。
  - When to use: 脑中有想法但落不了笔。
  - How: 对着录音解释给朋友听，再整理成段落。
- **注意力管理**: 写作需要隔离干扰、分解任务。

## Key Concepts
- **没的写**: 输入和经验不足。
- **不会写**: 缺少策略和结构。
- **不想写**: 心理阻抗和注意力耗散。

## Mental Models
- Use **draft as clay**: 没有泥就不能塑形。
- Think of writing as process, not final performance.

## Anti-patterns
- **等待完美状态**。
- **一边写一边苛刻评判**。
- **用仪式拖延启动**。

## Worked Example
论文卡住时，开一个20分钟计时器，口述“我到底想证明什么、证据有哪些、最担心哪里”。转写后只做分段和标注，不立刻润色。

## Key Takeaways
1. 写作障碍要分型处理。
2. 先有后好是核心策略。
3. 说话能复活记忆和秩序。
4. 管理注意力就是管理写作条件。
