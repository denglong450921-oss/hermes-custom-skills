# Chapter 9: 进阶：变量是思考的抓手

## Core Idea
变量思维把好奇心变成解释：比较差异，寻找机制。

## Frameworks Introduced
- **比较差异，寻找机制**: 从因变量的差异出发，寻找造成差异的自变量和过程。
  - When to use: 解释社会现象、历史变化、组织行为。
  - How: 明确结果变量，比较不同取值，排除不变因素，提出机制。
- **因果关系梯度**: 巧合、相关、因果、反事实推断、实验。
  - When to use: 判断论证强度。
  - How: 不把同时出现当成因果，尽量提出反事实。

## Key Concepts
- **变量**: 至少有两个取值的量。
- **常量**: 在当前分析中不变的因素。
- **因变量**: 要解释的结果。
- **自变量**: 可能造成结果差异的原因。

## Mental Models
- Use **moving things reveal relations** when analyzing.
- Think of mechanisms as the bridge between difference and explanation.

## Anti-patterns
- **正确的废话**: 用宏观口号替代具体机制。
- **刚愎的变量主义**: 忽视复杂性和边界条件。

## Worked Example
解释成衣工业兴起，不只说“生产力发展”，而追问：为什么可批量制造合身衣服？关键机制是人体测量数据发现常见尺寸组合，使库存和尺码成为可能。

## Key Takeaways
1. 变量让问题可分析。
2. 比较必须考虑控制。
3. 机制比口号重要。
4. 变量思维有边界，科学思维也要承认不确定。
