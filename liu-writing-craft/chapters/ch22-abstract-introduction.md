# Chapter 22: 脸面：摘要和引言的写法

## Core Idea
摘要和引言是文章的脸面；它们决定读者是否继续投入注意力。

## Frameworks Introduced
- **十遍法则**: 摘要和引言要比正文平均投入更多修改次数。
  - When to use: 投稿、答辩、报告提交前。
  - How: 反复检查问题、方法、发现、贡献是否清楚。
- **结构化摘要**: 问题、方法、发现、贡献。
  - When to use: 写学术摘要。
- **引言钩子**: 打钩子、有序呈现对比、阐释意义、连环刀推进。
  - When to use: 引入研究问题。

## Key Concepts
- **第一印象**: 读者快速形成判断。
- **确认偏误**: 开头差会让读者后续更容易挑错。
- **贡献**: 文章新增了什么理解。

## Mental Models
- Use **reader's chair**: 坐到读者椅子上看入口。
- Think of introduction as guided descent from world to question.

## Anti-patterns
- **背景铺太久**。
- **摘要只有主题没有发现**。
- **引言不说明贡献**。

## Worked Example
摘要模板：本文研究 X 问题；基于 Y 材料/方法；发现 A、B；说明 C 理论/实践意义。若任何格子为空，读者就难判断价值。

## Key Takeaways
1. 摘要必须交付发现。
2. 引言要制造问题和必要性。
3. 入口部件值得反复打磨。
4. 好引言把文献对话推向自己的问题。
