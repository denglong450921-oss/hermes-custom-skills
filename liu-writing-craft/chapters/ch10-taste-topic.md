# Chapter 10: 高阶：品味决定了选题的境界

## Core Idea
选题体现品味：知道什么值得做、什么不值得做，比把不值得的事做漂亮更重要。

## Frameworks Introduced
- **问题四象限**: 按问题大小和意义大小分为大大、大小、小小、小大。
  - When to use: 评估题目战略。
  - How: 初学者优先从小问题小意义练起，逐步连接大意义。
- **死胡同测试**: 清晰、有解、条件、时间、伦理。
  - When to use: 投入研究前。
  - How: 任一项严重不过关，就缩题或换题。
- **意义四把尺子**: 相关性、时间尺度、研究贡献、与福祉距离。
  - When to use: 判断题目价值。

## Key Concepts
- **品味**: 判断力和感知力。
- **刷新率**: 研究让读者想法改变多少。
- **镜头感**: 问题是否提供新观察工具。

## Mental Models
- Use **do right things before doing things right**.
- Think of small topics as training points that later connect.

## Anti-patterns
- **大鞋题目**: 题太大，跑不快。
- **选题迷恋**: 只焦虑方向，不把具体问题做完。

## Worked Example
“中美贸易战影响”过大。缩为“某出口企业在2018-2024年如何调整供应链？”小题可做，若机制清楚，也能连接贸易冲突的大意义。

## Key Takeaways
1. 品味可通过广读、坏例子和反馈训练。
2. 小题不等于小价值。
3. 判断题目要看可控性和意义。
4. 做完的能力同样重要。
