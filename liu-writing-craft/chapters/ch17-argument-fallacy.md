# Chapter 17: 论证与谬误

## Core Idea
论证不是吵架，而是用逻辑和证据证明观点；同时要警惕人脑和推理中的系统偏误。

## Frameworks Introduced
- **论证定义**: 观点需要理由和证据来支持。
  - When to use: 区分表达立场和完成证明。
  - How: 对每个判断追问“凭什么？”
- **谬误清单**: 流氓逻辑、忽悠、因果推理误区、研究环节偏误。
  - When to use: 检查草稿和他人观点。
  - How: 找偷换概念、循环论证、选择性证据、相关误作因果等。

## Key Concepts
- **观点**: 可争辩的判断。
- **事实**: 可被验证的陈述。
- **偏误**: 系统性认知或研究错误。

## Mental Models
- Use **from hands to words**: 合作社会需要用论证替代暴力。
- Think of fallacies as leaks in the argumentative pipe.

## Anti-patterns
- **把态度当论证**。
- **把故事当普遍证据**。
- **用相关冒充因果**。

## Worked Example
“我认识几个努力的人都成功了，所以努力必然成功。”这只是选择性故事。要论证，需要定义成功、测量努力、比较样本，并控制背景变量。

## Key Takeaways
1. 观点必须承担证明责任。
2. 人脑不天然可靠。
3. 谬误常隐藏在顺口的表达里。
4. 论证检查要贯穿研究各环节。
