# Chapter 6: 为什么不好好说话？

## Core Idea
坏风格不是小毛病，它常常遮蔽责任、制造门槛、偷懒或冒充专业。

## Frameworks Introduced
- **三种坏腔调**: 学生腔、学术腔、官腔。
  - When to use: 诊断难读、空泛、虚浮的文本。
  - How: 判断它是在抒情堆砌、概念轰炸，还是回避行动主体。
- **坏风格动机表**: 挑选读者、故弄玄虚、偷工减料、故作科学。
  - When to use: 解释为什么作者会主动写得难懂。
  - How: 问难懂是否带来身份、权威或责任逃避的收益。

## Key Concepts
- **学生腔**: 套话、抒情、宏大、空泛。
- **学术腔**: 专业术语和嵌套句过量。
- **官腔**: 大而化之、没有主体、信息密度低。

## Mental Models
- Use **翻译成人话** as a first revision pass.
- Think of bad style as polluted glass.

## Anti-patterns
- **概念轰炸**: 术语多但关系不清。
- **无主句**: “加强管理”“提高认识”，无人负责。
- **预制套话**: 句子可替换到任何文章。

## Worked Example
把“基于多元主体协同治理语境下推动机制优化”翻译为：“谁和谁合作？要解决什么问题？现在卡在哪里？下一步谁负责？”如果翻译后没有实质，原句就是烟雾。

## Key Takeaways
1. 坏风格会转嫁理解成本。
2. 学术写作不等于艰涩写作。
3. 官腔常通过无主体逃避责任。
4. 修改坏风格要恢复行动者、对象和关系。
