# Chapter 3: 怎样使用这本书？

## Core Idea
全书以十篇三十章训练说理写作，从分野、风格、提问、阅读、文献、论证、结构、流动、故事到视角。

## Frameworks Introduced
- **十篇三十章路线图**: 先转换写作观，再训练风格和问题，再进入阅读、文献、论证、结构、表达和读者视角。
  - When to use: 制定写作学习路径。
  - How: 按写作流程定位当下瓶颈，而不是从头平均学习。
- **四条线索**: 比较差异寻找机制、辩论、短篇/主题写作、电影与延伸阅读。
  - When to use: 把读书转为练习。
  - How: 每章读完至少做一次比较、一段写作或一次案例应用。

## Key Concepts
- **比较差异，寻找机制**: 全书最核心的变量思维线索。
- **短篇写作**: 用小练习练局部技能。
- **主题写作**: 用长任务整合多项能力。

## Mental Models
- Use **写作网** when treating chapters as互相连接的训练模块。
- Think of each chapter as a tool station: problem, evidence, structure, prose, reader.

## Anti-patterns
- **只收藏方法不练习**: 技术不经动手不会转化为手艺。
- **线性迷信**: 不根据自己的瓶颈选择章节。

## Worked Example
如果你的论文已经有材料但没有主线，先读 ch07-ch10 找问题；若问题清楚但说服力弱，读 ch17-ch18；若别人读不懂，读 ch23-ch24 和 ch28。

## Key Takeaways
1. 全书训练的是说理写作全流程。
2. 变量思维贯穿各篇。
3. 练习题是手艺训练，不是附录装饰。
4. 按瓶颈调取章节最有效。
