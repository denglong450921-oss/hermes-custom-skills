# Chapter 11: 读什么？

## Core Idea
写作从阅读开始；读什么决定你能看见什么、能和谁对话、能调动哪些材料。

## Frameworks Introduced
- **旗杆式知识结构**: 广泛阅读形成横向沟通能力，若干深度领域形成支点。
  - When to use: 设计长期阅读计划。
  - How: 保持通识宽度，同时建立几个可持续深挖的主题柱。
- **选书判断**: 看作者、出版社、反馈指标、时效和半衰期。
  - When to use: 过滤书单和文献。

## Key Concepts
- **分辨率**: 阅读提升对世界细节的识别能力。
- **伪书**: 看似有用但质量低、来源差的材料。
- **半衰期**: 知识随时间过时的速度。

## Mental Models
- Use **reading as input quality control**.
- Think of a reading list as intellectual diet, not a trophy shelf.

## Anti-patterns
- **只读畅销书单**。
- **只读本专业**，导致交流半径狭窄。
- **不辨来源**，把伪书当养料。

## Worked Example
为论文写作者配阅读：一部分读方法和写作书，补手艺；一部分读专业核心文献，补纵深；一部分读传记、历史和非虚构，补感知与材料。

## Key Takeaways
1. 好作者首先是好读者。
2. 阅读要兼顾广度、深度和质量。
3. 书与论文的时效、深度、风格不同。
4. 选材本身就是判断力训练。
