# Chapter 15: 尽信书不如无书：如何使用文献？

## Core Idea
文献不是印出来就可靠；写作者必须判断来源、内容、风格和使用方式。

## Frameworks Introduced
- **文献可信度四维**: 作者、媒介、内容、风格。
  - When to use: 判断一篇材料能不能引用。
  - How: 查作者资质、发表渠道、论证质量、是否有异常腔调。
- **文献分类管理**: 核心类、经典类、沾边类、瞎说类、聚集类。
  - When to use: 建立文献库。
  - How: 不同类别赋予不同阅读深度和引用权重。
- **引用方式**: 脚注、尾注、夹注、直接引用、间接引用。
  - When to use: 避免剽窃和误引。

## Key Concepts
- **水刊/论文工厂**: 低质量发表生态。
- **查重**: 形式检查不能替代规范意识。
- **间接引用**: 用自己的话转述并标注来源。

## Mental Models
- Use **trust but verify** for every source.
- Think of citation as intellectual accountability.

## Anti-patterns
- **正规出版迷信**。
- **复制漂亮句子**。
- **引用没读过的二手材料**。

## Worked Example
看到一篇结论惊人的论文，先查期刊和作者，再看方法和数据，最后判断是否被其他核心文献引用或批评。若来源可疑，只能作为现象材料，不能作为论据。

## Key Takeaways
1. 文献有质量等级。
2. 使用文献前要判断可信度。
3. 引用规范体现学术诚信。
4. 管理分类能节省阅读成本。
