# Cheatsheet

## Decision Rules

| Situation | Do This | Because |
|---|---|---|
| 题目太大 | 缩到一个对象、一个关系、一个时间/场景 | 初学者先做可控题目，完成比宏大更重要 |
| 不知道写什么 | 先问问题，不先找材料 | 问题是文章引擎，材料只是燃料 |
| 问题不吸引人 | 改写成谜题 | 反差和矛盾能激发读者追问 |
| 解释太宏观 | 找变量和机制 | “生产力发展了”常是正确废话 |
| 文章晦涩 | 改成透明玻璃风格 | 说理写作让读者看见对象，不欣赏玻璃 |
| 文献堆砌 | 用 They say/I say 重组 | 综述是对话，不是书单 |
| 观点没力量 | 画论证树 | 主张、理由、证据必须逐层连接 |
| 摘要引言弱 | 用十遍法则优先修改 | 入口决定读者是否继续 |
| 段落难读 | 一段一点，主题句靠前 | 懒人读者需要导航 |
| 写不出来 | 先有后好，以说带写 | 草稿先解决“有”，修订再解决“好” |

## Topic Triage

| Question Type | Diagnosis | Next Move |
|---|---|---|
| 大问题大意义 | 有诱惑但高风险 | 只在资源、数据、能力足够时做 |
| 大问题小意义 | 费力不讨好 | 放弃或缩小 |
| 小问题小意义 | 初学者练功题 | 做深、做扎实，积累经验 |
| 小问题大意义 | 理想切口 | 用具体案例连接重要机制 |

## Dead-End Test

1. 问题是否清晰：因变量和自变量能说清吗？
2. 问题是否有解：能验证吗？有事实基础吗？
3. 条件是否具备：数据、技术、现场、文献够吗？
4. 时间是否充足：能在期限内完成一个完整循环吗？
5. 伦理是否过关：会不会伤害研究对象或违反规范？

## Literature Review Quick Form

| Source | They Say | Method/Evidence | Gap/Limit | I Say |
|---|---|---|---|---|
| 论文/书 | 它的核心观点 | 它凭什么这么说 | 它没解决什么 | 我如何接上、修正或反驳 |

## Style Smells

| Smell | Likely Problem | Fix |
|---|---|---|
| 名言堆砌 | 学生腔 | 换成自己的问题和证据 |
| 概念轰炸 | 学术腔 | 翻译成人话，再决定术语是否必要 |
| 没有主语 | 官腔 | 写出行动者和责任主体 |
| 段落半页 | 读者成本过高 | 切成主题明确的小段 |
| 题目抽象空泛 | 不可操作 | 加对象、关系、范围、时间 |

## Revision Order

1. 问题是否值得问。
2. 观点是否回答问题。
3. 理由和证据是否支撑观点。
4. 结构是否让读者顺着走。
5. 标题、摘要、引言是否让人愿意读。
6. 句子和段落是否透明、具体、流动。
