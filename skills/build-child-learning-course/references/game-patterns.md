# Learning game library

Use games as retrieval structures, not decoration. Choose a game because its learner action produces evidence for the current objective. A new theme, color, character, or reward does not create a new game type when the learner performs the same cognitive operation.

## Diversity rule

- Treat the 16 entries as a selection library, not a checklist for one course.
- For a course of 10 or more days, select **four to six core game IDs** that fit the learning objectives.
- Use each core engine at least three times across onboarding, consolidation, and transfer.
- Keep a primary game for a two- or three-session arc when the stable interface supports deeper content.
- Include both recognition and production evidence across the selected set.
- Use one or two games per day; do not place all game types on one page.
- Avoid one-off games and a disconnected “different genre every day” plan.
- Keep games short enough that instructions do not consume the learning time.

## Selection matrix

| Need | Prefer |
|---|---|
| Connect two representations | G01 |
| Discriminate sound | G02 or G16 |
| Produce from memory | G03 or G15 |
| Form a category or rule | G04 or G12 |
| Learn order or procedure | G05 |
| Construct a whole from parts | G06 |
| Retrieve a missing element | G07 |
| Learn from misconceptions | G08 |
| Sustain multi-clue retrieval | G09 |
| Connect language or concept to movement | G10 |
| Repeated recognition across a mixed set | G11 |
| Make dependent decisions | G13 or G14 |

## G01 · 翻牌配对 Memory Match

- **玩法家族**：连接
- **核心动作**：翻开两张卡，把图片、声音、文字、数量模型或符号配成有意义的一对。
- **记忆机制**：提取练习、双重编码、即时反馈。
- **适用学科**：英语、数学、语文、科学。
- **独立证据**：学习者在遮盖状态下找到跨表征对应关系；兼有识别证据。
- **实现规则**：每次开始和重玩都用 Fisher–Yates 洗牌；匹配依据稳定键而非位置；翻牌播放对应本地音频；错配后重新盖住；正确对可再次遮盖和重练。
- **避免**：图片卡与文字卡固定分成上下两排，或点击后卡片根本没有遮盖状态。

## G02 · 听音侦探 Sound Detective

- **玩法家族**：辨别
- **核心动作**：听一个本地音频，在无答案标签的图片、字符、数字或动作中选择唯一答案。
- **记忆机制**：听觉辨别、测试效应、错误对比。
- **适用学科**：英语、语文、音乐、数学口算。
- **独立证据**：学习者只凭声音识别目标；属于识别证据。
- **实现规则**：每题恰好一个正确项；干扰项来自已学内容；选错后允许重听；音频、图片和答案来自同一内容记录。
- **避免**：测试图片直接印出答案文字，或题目音频与图片映射错位。

## G03 · 看图开口 Picture Recall

- **玩法家族**：生成
- **核心动作**：看一张无标签图片、模型或情境，先说出词语、句子、算式或解释，再揭晓答案。
- **记忆机制**：生成效应、提取练习、元认知校准。
- **适用学科**：英语、数学、语文、科学。
- **独立证据**：记录“已作答”与“答对”而不是把点击揭晓当作掌握；属于产出证据。
- **实现规则**：先提供“我说好了”按钮，再允许揭晓或播放；可录入家长判定；答案出现后提供一次延迟重试。
- **避免**：答案一直可见，或只有“认识/不认识”的主观自评。

## G04 · 分类小篮子 Sorting Baskets

- **玩法家族**：分类
- **核心动作**：把项目拖放或点选到两个至四个有意义的类别中，并说明分类规则。
- **记忆机制**：概念形成、对比学习、自我解释。
- **适用学科**：英语、数学、语文、科学、社会。
- **独立证据**：学习者能区分正例、反例和边界例；兼有识别与产出证据。
- **实现规则**：类别数量符合年龄；可用点击替代拖拽；放置后给出具体原因；最后隐藏标签再分一个新例子。
- **避免**：按颜色等无关装饰分类，或让不会拖拽成为失败原因。

## G05 · 顺序小火车 Sequence Train

- **玩法家族**：排序
- **核心动作**：排列字母、笔画、故事事件、数轴位置、算法步骤或过程阶段。
- **记忆机制**：序列编码、组块化、程序性提取。
- **适用学科**：英语、数学、语文、科学、音乐。
- **独立证据**：学习者重建正确顺序并能指出相邻关系；兼有识别与产出证据。
- **实现规则**：首次可显示位置槽，随后淡出提示；支持键盘与点击换位；提交后突出第一个断点而非直接重排全部。
- **避免**：动画先完整演示答案后立即要求照抄。

## G06 · 拼搭工坊 Build It

- **玩法家族**：构建
- **核心动作**：用部件拼成单词、句子、汉字、图形、数量或算式。
- **记忆机制**：生成效应、部分—整体联结、操作性表征。
- **适用学科**：英语、数学、语文、科学。
- **独立证据**：学习者从可选部件中构造目标并解释部件作用；属于产出证据。
- **实现规则**：部件可点击加入和撤回；保留可接受的多种答案；提示按“方向—首部件—完整示范”逐级出现。
- **避免**：只有一个显眼部件可选，或界面自动吸附成答案而无需判断。

## G07 · 消失的一块 Missing Piece

- **玩法家族**：补全
- **核心动作**：补出被遮住的字母、词、字符、数字、步骤、图形部分或节奏拍。
- **记忆机制**：模式完成、线索提取、渐隐支架。
- **适用学科**：英语、数学、语文、音乐。
- **独立证据**：学习者利用剩余线索生成缺失部分；兼有识别与产出证据。
- **实现规则**：从单个缺口逐步增加；接受输入、选择或口述判定；错误反馈指出应使用的线索。
- **避免**：缺口旁保留完全相同的答案示例。

## G08 · 错误小医生 Error Doctor

- **玩法家族**：纠错
- **核心动作**：发现一个常见错误，指出错误位置并修正或解释。
- **记忆机制**：错误辨别、抑制误概念、自我解释。
- **适用学科**：英语、数学、语文、科学。
- **独立证据**：学习者不仅判断对错，还能提交正确版本或理由；属于产出证据。
- **实现规则**：错误来自真实易错点；先让孩子判断再解释；反馈对比错误规则与正确规则；语气把错误当线索。
- **避免**：用怪异答案充当错误，或只给红叉不说明下一步。

## G09 · 线索寻宝 Clue Hunt

- **玩法家族**：线索检索
- **核心动作**：根据两至三条逐步出现的声音、图像、属性或关系线索找出目标。
- **记忆机制**：精细加工、间隔提取、线索整合。
- **适用学科**：英语、数学、语文、科学、地理。
- **独立证据**：记录学习者用到第几条线索以及最终答案；兼有识别与产出证据。
- **实现规则**：第一条线索最有诊断价值；允许先猜；线索逐条揭示；完成后要求说出决定性线索。
- **避免**：寻宝只是在页面上找一个闪烁按钮，与知识目标无关。

## G10 · 动作指令 Action Command

- **玩法家族**：动作
- **核心动作**：听或读指令后做动作、指向实物、摆放物体、拍节奏或移动角色。
- **记忆机制**：具身认知、听觉—动作联结、延迟反应。
- **适用学科**：英语、数学、语文、音乐、体育。
- **独立证据**：由家长轻触确认、摄像头外观察或下一步结果确认动作；属于产出证据。
- **实现规则**：动作与语义直接对应；提供重复播放和无障碍替代；逐渐从单步过渡到短序列。
- **避免**：与知识无关的跳舞奖励，或要求危险、空间过大的动作。

## G11 · 知识宾果 Learning Bingo

- **玩法家族**：混合识别
- **核心动作**：在随机棋盘中根据声音、定义、算式、偏旁或线索标记对应格。
- **记忆机制**：交错练习、重复检索、辨别。
- **适用学科**：英语、数学、语文、科学。
- **独立证据**：每一次标记都保存题目键和选择键；属于识别证据。
- **实现规则**：棋盘和提示顺序每轮重排；每个提示只有一个当前正确格；错误格不永久锁死；完成一线后仍可继续全盘挑战。
- **避免**：格子显示与提示完全相同的答案文字而无需转换。

## G12 · 谁不一样 Odd One Out

- **玩法家族**：比较
- **核心动作**：从三至四项中找出不属于同一规则的一项，并选择或说出理由。
- **记忆机制**：对比学习、概念边界、自我解释。
- **适用学科**：英语、数学、语文、科学、艺术。
- **独立证据**：答案与理由分开记录；合理的替代理由可由成人接受；兼有识别与产出证据。
- **实现规则**：预先定义目标规则；项目在无关视觉特征上保持均衡；先选择后解释。
- **避免**：只有某一项颜色或尺寸明显不同，泄漏学科答案。

## G13 · 先猜再看 Predict and Reveal

- **玩法家族**：预测
- **核心动作**：先预测故事下一步、实验结果、数形变化、发音或规则应用，再运行语义动画验证。
- **记忆机制**：预测误差、因果模型、反馈学习。
- **适用学科**：数学、科学、英语、语文。
- **独立证据**：保存预测、结果和修正解释；兼有识别与产出证据。
- **实现规则**：动画只在提交预测后开始；结果过程可暂停重放；追问“哪里和你想的不一样”。
- **避免**：预测前播放完整过程，或把惊喜动画当作学习目标。

## G14 · 决策迷宫 Decision Path

- **玩法家族**：策略
- **核心动作**：在连续两至四个节点作出相互依赖的选择，帮助角色解决题目或完成任务。
- **记忆机制**：迁移、策略选择、因果反馈。
- **适用学科**：数学、语文、英语、科学、社会。
- **独立证据**：记录每个节点的选择与理由，而不只记录是否到达终点；兼有识别与产出证据。
- **实现规则**：路径由知识决策决定；错误支路提供恢复题；地图位置不能暗示正确答案；支持重新走不同路径。
- **避免**：纯随机迷宫、反应速度游戏或只有一条可点击道路。

## G15 · 小老师挑战 Teach Back

- **玩法家族**：表达
- **核心动作**：向玩偶、家长或屏幕角色解释规则、讲故事、读句子、演示解法或教一个字。
- **记忆机制**：自我解释、检索组织、费曼式精加工。
- **适用学科**：英语、数学、语文、科学。
- **独立证据**：使用二至三个可观察要点进行成人勾选或学习者录音；属于产出证据。
- **实现规则**：给短句框架但逐步淡出；提供示例评价标准；先完成表达再播放范例。
- **避免**：只让孩子点击“我会了”，没有任何可观察表达。

## G16 · 节奏回声 Rhythm Echo

- **玩法家族**：模仿编码
- **核心动作**：听一段音节、数字、声调、拍子或步骤节奏，等待后按相同顺序复现。
- **记忆机制**：语音环路、节奏组块、延迟模仿。
- **适用学科**：英语、语文、数学、音乐。
- **独立证据**：比较复现序列与目标序列；属于产出证据。
- **实现规则**：从二至三个单位开始；播放时锁定作答；播放结束后再开放输入；速度可调但不以最快为优。
- **避免**：同时显示完整视觉答案，或把低龄儿童按键速度当成掌握度。

## Rotation protocol

1. Tag the daily objective as connection, discrimination, production, classification, sequence, construction, correction, transfer, or explanation.
2. Select four to six core engines whose combined learner actions cover the course outcomes.
3. Introduce each engine once, then reuse it with faded support and more demanding content.
4. Organize short arcs: onboarding → consolidation → transfer.
5. Select an optional secondary game when it adds a different evidence type, not merely more novelty.
6. Replace one-off mechanics and cosmetic reskins with purposeful repetitions.
7. Schedule yesterday's content in the first testing block, then revisit older content after three to seven days.
8. Validate the final plan with `scripts/validate_game_diversity.py`.
