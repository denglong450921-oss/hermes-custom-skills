# Subject adaptation patterns

Select the relevant section and preserve the shared mastery loop from `SKILL.md`.

## English

Build connections among sound, print, meaning, and use.

### Recommended content unit

- letter, phoneme, word, or phrase;
- clear local picture without answer text;
- child-friendly Microsoft Neural TTS audio;
- short useful sentence;
- gesture or semantic animation;
- recognition and spoken recall tasks.

For alphabet courses, use multiple words per letter when daily volume would otherwise be too low. Prefer familiar words and short everyday sentences. Treat difficult letters such as X explicitly instead of forcing obscure vocabulary.

### Useful activities

- hear a sound and select a picture;
- open a randomized picture–word pair;
- look at a clean picture and say the word;
- arrange words into a short sentence;
- follow a spoken action command;
- compare easily confused sounds.

Do not show the English word inside an image used for recall or listening assessment.

For a long course, select four to six suitable core engines from G01, G02, G03, G04, G05, G06, G07, G08, G09, G10, G11, G12, G15, and G16. Reuse them across sound, print, meaning, and sentence-transfer stages instead of teaching a new interface every day.

## Mathematics

Move through **concrete → representational → abstract**.

### Recommended content unit

- real or simulated objects;
- visual model such as dots, ten frames, number lines, arrays, or shapes;
- mathematical symbol or equation;
- spoken reasoning prompt;
- misconception-based distractors;
- one transfer problem in a new context.

### Useful activities

- drag objects to make a quantity;
- animate joining, separating, grouping, or partitioning;
- match an object model to an equation;
- place a number on a line;
- sort examples and non-examples;
- explain “how you know” with a sentence frame.

Never animate the final answer before the child attempts the problem. Avoid speed scoring until accuracy and strategy are established.

For a long course, select four to six suitable core engines from G01, G02, G03, G04, G05, G06, G07, G08, G09, G10, G11, G12, G13, G14, and G15. Reuse the same engines while moving from concrete → representational → abstract so the child's attention stays on mathematical reasoning.

## Chinese

Connect sound, shape, meaning, component structure, and usage.

### Recommended content unit

- character;
- pinyin and tone audio when appropriate;
- semantic picture;
- radical or component;
- stroke-order animation;
- familiar word or short sentence;
- recognition plus writing or oral production.

### Useful activities

- hear a syllable and choose the character;
- match character, picture, and word;
- trace strokes in order;
- assemble components into a character;
- distinguish similar characters;
- read a short phrase, then choose its meaning.

Hide pinyin and character labels during independent picture recall. Animate strokes sequentially and provide a replay button.

For a long course, select four to six suitable core engines from G01, G02, G03, G04, G05, G06, G07, G08, G09, G10, G11, G12, G14, G15, and G16. Reuse them across sound, shape, meaning, component, sequence, and oral-production stages rather than merely changing the character set.

## Other subjects

Map the subject into:

1. a concrete or perceptible representation;
2. a symbolic or verbal representation;
3. an action the learner can perform;
4. a common misconception;
5. an independent mastery task.

Examples:

- science: observe → predict → animate process → test prediction;
- music: hear → imitate → identify → sequence;
- geography: locate → compare → reconstruct a map;
- coding: predict → run → debug → explain.

## Fifteen-day progression pattern

Use this only as a starting point:

- Days 1–3: onboard the first core games and establish the daily 30/70 rhythm;
- Days 4–6: consolidate familiar game engines with harder content;
- Days 7–9: introduce correction or construction inside the same visual world;
- Days 10–12: transfer the core engines to mixed and less-supported tasks;
- Days 13–14: cumulative testing with production and explanation;
- Day 15: mastery challenge using familiar mechanics, followed by celebration.

Change the duration and pacing to fit the actual scope.
