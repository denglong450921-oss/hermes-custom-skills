# Learning science mechanisms

Use the smallest combination of mechanisms that supports the objective. More effects and more motion do not automatically produce more learning.

## Mechanism map

| Mechanism | Course implementation | Failure signal |
|---|---|---|
| Cognitive load control | Teach one new idea at a time; group related controls; keep sentences short | The child watches but cannot explain what to do |
| Dual coding | Pair a word or idea with a relevant image, sound, gesture, or model | Decorations compete with the target idea |
| Retrieval practice | Ask the learner to answer before revealing the solution | The answer is printed on the test image |
| Testing effect | Use frequent low-stakes checks with immediate correction | Testing appears only on the final day |
| Spacing | Revisit content after minutes, one day, three days, and one week | A topic disappears after its lesson |
| Interleaving | Mix a small number of previously learned item types | Random tasks include content never taught |
| Scaffolding | Model, prompt, fade support, then test independently | Hints never disappear |
| Embodied cognition | Attach gestures or object manipulation to suitable concepts | Movement is unrelated entertainment |
| Feedback | Name the correct idea and the next action | Feedback only says “wrong” |
| Motivation | Reward effort, strategy, and return attempts | Stars become the only goal |

## Age calibration

### Ages 5–7

- Prefer 15–30 minute sessions, with an optional break.
- Use one-step instructions and large touch targets.
- Alternate listening, moving, touching, and speaking.
- Keep working-memory demand low: usually 2–4 elements at once.
- Let a parent read Chinese directions when needed.
- Treat willingness to respond as progress, while still measuring accuracy separately.

### Ages 8–10

- Increase independent reading and multistep tasks gradually.
- Ask the learner to explain a strategy, not just give an answer.
- Use error comparison and mixed review.
- Add simple self-rating only after an objective task.

## Daily memory schedule

For a new item:

1. Attend to one clear model.
2. Imitate with support.
3. Retrieve within the same session.
4. Retrieve again near the end of the session.
5. Revisit on the next day.
6. Revisit in a mixed set after three to seven days.

Do not count replaying the same animation as retrieval. Retrieval requires the learner to produce, choose, arrange, or explain before seeing the answer.

## 30% learning / 70% testing

Use the ratio as a design budget, not a decorative progress label:

- **Learning 30%:** concise modeling and one fading worked example.
- **Testing 70%:** previous-day retrieval, two game-based response rounds, and an exit challenge.

A testing minute begins when the learner receives a prompt and ends after a response, feedback, and an optional retry. An explanation shown before any response belongs to learning time. Keep the ratio across the whole daily session and verify it from the activity plan.

Start Day 2 and every later day with retrieval from the immediately previous day. This fast feedback loop catches fragile learning before new material compounds it. Add three-day and seven-day items after the previous-day review, not instead of it.

## Assessment design

Use at least two forms of evidence:

- **Recognition:** choose, match, sort, or identify.
- **Production:** say, write, build, draw, or explain.

Record attempts separately from correct responses. Permit replay without deleting unrelated progress. Use distractors based on plausible confusions, not arbitrary images.

## Animation rules

- Animate the semantic action: a ball bounces, groups combine, a stroke draws in order.
- Begin motion through a deliberate learner action.
- Highlight only the active item.
- Provide replay and pause.
- Honor `prefers-reduced-motion`.
- Never move answer choices during a response.

## Productive variety

Use variation to change the retrieval demand without constantly changing the interface. Select a small set of practical core games, teach their rules once, and deepen them through harder content, faded support, delayed recall, mixed examples, and transfer. A familiar game reduces interface load and leaves more attention for learning. Keep one or two games on a daily page and reserve the larger library for deliberate course-level selection.
