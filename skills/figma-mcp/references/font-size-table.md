# Font Size Quick Reference

Empirically derived from translating 20+ casino/promotional pages (800px wide frames) across 4 languages.

## By Original Font Size

| Original | Spanish | French | Portuguese | Arabic |
|----------|---------|--------|------------|--------|
| 40px Inknut Antiqua | 32px | 34px | 34px | 40px |
| 50px Inder | 50px | 34px | 34px | 50px |
| 60px Holtwood One SC | 48px | 48px | 48px | 60px |
| 80px DIN Alternate | 80px | 48px | 48px | 80px |
| 35px Inter (desc) | 26px | 26px | 26px | 35px |
| 32px Inter (col hdr) | 22px | 22px | 22px | 32px |
| 28px Inter (disc) | 20px | 20px | 20px | 28px |
| 24px Inter (body) | 24px | 20px | 20px | 24px |

## By Language

### Spanish
- Most headings: -20% (40→32, 60→48)
- Column headers always 22px
- DIN Alternate at 80px fits unchanged (condensed)

### French
- Most headings: -20% to -25%
- Slightly more reduction than Spanish
- Column headers always 22px
- Inknut Antiqua needs 34px (one step smaller than Spanish's 32px)

### Portuguese
- Same ratios as Spanish
- Column headers always 22px

### Arabic
- Almost never needs reduction
- Arabic script is naturally compact
- Only check headings above 60px with wide display fonts
