# Title Generation Rules — Reference

## Title length guidelines by style

| Style | Target chars | English words | Structure |
|---|---|---|---|
| professional | 15-25 | 8-15 | [领域] + [核心概念] + [方法] |
| high-level | 18-30 | 10-18 | [领域] + [概念] + [系统/路径] |
| cognitive | 15-28 | 8-16 | [概念] + [方法论] + [思维模型] |

## Title structure patterns

```
[Domain] + [Core concept] + [Methodology/path/system]
```

### Good examples

| Style | Example |
|---|---|
| professional | "AI 时代的 OPC：如何用最小系统跑通一个人的商业闭环" |
| professional | "认知写作：从信息输入到结构化表达的系统方法" |
| high-level | "个人商业系统：从需求验证到 MVP 到可持续收入的完整路径" |
| cognitive | "第二大脑方法论：如何构建可复用的知识管理系统" |
| high-level | "OKR 驱动的组织变革：从目标设定到执行闭环" |

## No-clickbait patterns to avoid

| Pattern | Why bad | Correct instead |
|---|---|---|
| "震惊" "惊呆" | Low credibility, may trigger WeChat review | Use substantive methodology descriptor |
| "99%的人都不知道" | Untrue claim, reduces trust | "多数人忽略的方法" or just state the method |
| "再不XX就晚了" | Fear-based FOMO, damages brand | "为什么现在是最佳时机" with reasoning |
| "全网疯传" | Inflated, usually untrue | Remove entirely — let content speak |
| "跪了" "哭晕" | Excessive, unprofessional | Use measured language |

## Tag generation guidelines

- Always 3 tags
- Tags should be [domain keyword] · [concept] · [method]
- Keep each tag under 10 chars for Chinese, 15 chars for English
- No spaces around middle dots (·)
