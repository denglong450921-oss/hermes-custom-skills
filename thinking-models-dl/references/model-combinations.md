# 模型组合策略

> 思维模型单独使用时解释力有限，组合使用才构成完整的分析框架。按常见搭配场景整理。

## 常用搭配

### 组合A：因果链分析（最常用）

```
二阶思维 + 系统思维 + 飞轮效应
```

**适用**：解释「为什么事情会变成这样」「恶性循环如何形成」  
**文章结构**：二阶思维看表面原因→系统思维看反馈回路→飞轮效应看累积效应  
**例**：「越努力越焦虑」= 努力→期望变形（二阶）→ 增强回路（系统）→ 自我强化（飞轮）

### 组合B：结构拆解（Dennon 默认）

```
第一性原理 + 三层结构模型 + 临界点思维
```

**适用**：系统分析类文章（教育、健康、认知）  
**文章结构**：第一性原理拆到不可再分→三层递进建结构→临界点找出杠杆  
**例**：「学习的本质」= 提取而非输入（第一性）→ 检索/重构/迁移（三层）→ 主动回忆的频率跨过阈值（临界点）

### 组合C：认知纠偏

```
汉隆剃刀 + 二阶思维 + 认知重构
```

**适用**：破除广泛认知误区的文章  
**文章结构**：汉隆剃刀降低情绪负荷→二阶思维揭示隐藏代价→认知重构换框架  
**例**：「刷手机=放松」→ 不是恶意是设计（汉隆）→ 注意力碎片化（二阶）→ 将放松重新定义为「主动休息」（重构）

### 组合D：决策分析

```
成本收益分析 + 机会成本 + 时间贴现 + 10/10/10法则
```

**适用**：选择困境、人生决策分析  
**文章结构**：算清显性和隐性成本→看清被放弃的选项→对抗短期偏好→拉长时间轴  
**例**：「要不要辞职自由职业」→ 显性/隐性成本→ 放弃的B选项→ 时间贴现偏见→ 10年后怎么看

### 组合E：效率诊断

```
帕累托法则 + 能量管理 + 艾森豪威尔矩阵
```

**适用**：效率低下、时间管理问题  
**文章结构**：二八法则找出高杠杆活动→能量管理匹配高难度时段→四象限区分真紧急和假紧急  

### 组合F：关系分析

```
信任公式 + 乔哈里视窗 + 第二支箭
```

**适用**：沟通障碍、关系冲突分析  

## 避坑指南

| 不要 | 为什么 |
|------|--------|
| 一篇文章推荐超过4个模型 | 每个模型都需要展开解释，超过4个会稀释分析深度 |
| 推荐同分类的两个模型处理同一个层次 | 同分类模型容易重复（如用两个「战略」模型解释同一件事），选最有解释力的那个 |
| 模型之间没有递进关系 | 并列的模型堆在一起不如递进的链条有力。确保模型A的结论是模型B的前提 |
| 只推荐不展开 | 「推荐了3个模型但没有解释每一个为什么匹配」违反了SKILL.md的输出规范 |
